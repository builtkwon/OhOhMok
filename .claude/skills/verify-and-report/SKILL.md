## MUST

- 아래 명령은 실제로 실행하고 종료코드와 FAIL 원문을 보고에 옮긴다. 실행하지 않은 것은 완료로 쓰지 않는다.
- 실패 수정은 작업 범위당 3회까지(자체+독립 리뷰 합산). 넘으면 멈추고 보고한다.
- 검증하지 못했으면 "구현 완료, 검증 미완료"로 보고한다.

## 단계

- S1 단위: `npm test` (항상).
- S2 UI: 화면·입력·레이아웃·index.html을 바꿨으면 `npm run test:ui`(Playwright 로컬, 처음이면 `npx playwright install chromium`).
- S3 방: 방·네트워크·시계를 바꿨으면 `npm run test:team`(인터넷 필요). 망이 없어 못 돌리면 사유와 함께 미검증으로 쓴다.
  - S1~S3 실패 → 고친 뒤 S1부터 다시.
- S4 독립 리뷰 판정: 아래 중 하나면 reviewer에 요청하고, 아니면 "불필요(근거)"를 한 줄 쓴다.
  - 이음새 변경(메시지·저장 키·CSS 변수·DOM id·전역 함수)
  - 저장 데이터 이전(예: `ohohmok-` 키 복사), 로그인·개인정보·사진 전송
  - 방장 검증(차례·금수·시간) 로직, index.html 분할
  - 요청 시 전달물: 요청 원문, 승인 범위, `git diff main...`, 실행한 명령 출력, 완료 보고 초안.
- S5 완료 보고:
  - 변경: 만든·고친·지운 파일
  - 실제 실행한 명령·결과: 명령, 종료코드, 통과/실패 수
  - 미검증 범위: 돌리지 않은 테스트와 사유, 손으로만 본 것
