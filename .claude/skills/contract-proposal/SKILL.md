## MUST

- 이음새와 owns 밖 파일(package.json 포함)은 읽기만 한다. 변경은 사용자 합의 후 integrator가 반영한다.
- TODO-CONTRACT.md는 자기 역할 섹션(`## profile-dev` / `## room-dev` / `## ui-dev` / `## ai-dev`) 안, `<!-- end:<역할> -->` 줄 바로 위에만 추가한다.
- 다른 섹션, 끝 표시 줄, `## 양식`은 고치지 않는다(병렬 worktree 머지 충돌 방지).
- 제안 하나에 항목 하나. 기존 항목은 고치지 않고 새 항목으로 낸다.

## 단계

- S1 부족 확인: 필요한 이름이 정말 없는지, 기존 메시지·키로 해결되지 않는지 본다.
  - 현재 이음새 → docs/rules/README.md#이음새, 경로별 소유 → AGENTS.md 표와 각 에이전트 frontmatter `owns`
  - 기존 것으로 되면 제안하지 않고 그것을 쓴다.
- S2 제안 작성: `## 양식`대로 쓴다. 메시지는 방향(G→H / H→G)과 필드, 저장 키는 `ohohmok-` 접두사와 값 형식, 호환(옛 클라이언트·옛 데이터) 대응을 적는다.
- S3 보고: 제안 제목과 진행 여부(대기 / 무관한 부분 계속)를 완료 보고에 쓴다.
  - 합의 전에 임시 메시지·키를 코드에 넣지 않는다(금지).
