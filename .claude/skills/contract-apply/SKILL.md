## MUST

- 사용자 합의 없이 이음새를 바꾸지 않는다.
- 항목을 지울 때 `## <역할>` 섹션 제목과 `<!-- end:<역할> -->` 줄은 남긴다.
- 메시지·저장 키 변경은 옛 클라이언트·옛 데이터 호환을 확인한다(모르는 `type` 무시, 키 이전은 한 번만·옛 키 보존).
- 이음새 변경은 독립 리뷰 대상이다(verify-and-report S4).

## 단계

- S1 항목 확인: 역할 섹션의 항목과 영향 역할을 읽는다.
- S2 합의: 항목별 반영 / 수정 반영 / 보류를 사용자에게 묻고 답을 받는다.
- S3 반영: 합의한 항목만. 코드 변경은 소유 역할 브랜치에 배정하거나 합의 범위 안에서 직접 한다. docs/rules/README.md#이음새 목록을 함께 고친다.
- S4 항목 삭제: 반영한 항목만 지운다. 보류 항목은 그대로 둔다.
- S5 verify-and-report로 이어간다(독립 리뷰 조건 해당).
